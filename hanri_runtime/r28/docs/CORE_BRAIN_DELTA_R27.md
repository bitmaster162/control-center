# CORE / BRAIN Candidate Delta R27

Status: `CANDIDATE / PROMPT-LEVEL ONLY`

## CORE additions

### Count-universe binding
Every quantitative claim must bind to:
- `universe_id`;
- denominator;
- subset relation;
- overlap/disjoint semantics;
- measurement class and event time.

A declared disjoint partition that does not sum to its total is `REVISE`.

### Occurrence versus evidence family
Physical copies, paths and wrappers are occurrences. Independent support is counted by evidence family and provenance.

### Authority-surface register
Every mutable path or external target must have one explicit authority status. More than one current mutable authority without a verified broker yields `HOLD`.

### Specification/implementation split
A coherent canon, architecture or research report remains a specification until exact source/Git/runtime/effect receipts prove implementation.

### Proof-ledger minimum fields
A proof record requires at least:
`proof_id`, source/evidence-family identity, verification method, status, observation time and optional signature/readback.

## BRAIN additions

New reflex:

```text
COUNT → BIND UNIVERSE
COPY → BIND EVIDENCE FAMILY
CANON → CHECK IMPLEMENTATION
MUTATION → CHECK AUTHORITY SURFACE
PROOF → CHECK PROOF IDENTITY
```

The original BitEvo Unified Canonical State is retained as design intent, not current-state authority.
