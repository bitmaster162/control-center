# Per-Turn Improvement Protocol R24

This protocol can be applied in every substantial chat turn without exposing private chain-of-thought.

## Before a step

Record:
- exact goal;
- accepted decisions that must not change silently;
- evidence gap;
- current PAST/PRESENT/FUTURE plane;
- tool and resource budget;
- action reversibility and authority ceiling.

## After every tool result

Check:
- what physical object or provider response was actually received;
- strongest completed effect rung;
- target-state readback;
- conflicts with current state;
- new unknowns;
- whether the result changes the decision.

## After every substantive step

Ask only:

```text
Did this change a decision?
Did this add independent evidence?
Did this close/open a material gap?
Did this improve a control?
```

If all four are no, stop recursive analysis.

## Before the final answer

Check:
- all active lanes have a disposition;
- no completed work is being rerun;
- no one-folder absence is called globally missing;
- simulation is not current fact;
- tool success is not effect proof;
- no hidden/background-work claim;
- operator burden is minimized;
- one actionable next gate remains.

## After Robert corrects the system

Create:
- failure class;
- exact correction;
- smallest rule delta;
- regression case;
- supersession record if an accepted decision changes.

The delta remains a candidate until Robert accepts it.
