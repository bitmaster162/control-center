# Human-AI Native Contract R24

A system is **AI-native** when machines receive explicit identities, schemas, provenance, state transitions, effect levels, resource budgets and stop conditions.

A system is **human-native** when Robert receives comprehensible decisions, visible uncertainty, meaningful alternatives, costs, reversibility, an exit path and minimal copy/paste burden.

Neither interface is a translation afterthought. They are two views of one event.

## Shared identity

Every material event has one stable ID and hash.

```text
Human Decision Card
        ↕ same Candidate ID
AI Candidate Delta Record
```

## Human view

Required fields:
- what changed;
- why it matters;
- evidence and uncertainty;
- smallest proposed change;
- risk and reversibility;
- how to test it;
- `ACCEPT | REVISE | HOLD | REJECT`;
- what happens if no action is taken.

## AI view

Required fields:
- task/step/event IDs;
- actor/session/workspace/work-order binding where applicable;
- evidence class, source identity, freshness and hash;
- accepted decisions and explicit supersession;
- unknowns;
- action class and effect rung;
- resource/attention cost;
- regression case;
- stop condition.

## Human agency

- Model agreement is not social proof.
- Recommendations do not become authority by fluency.
- Critical action requires human approval and deterministic precondition checks.
- Robert may pause, export, supersede or reject any candidate.
- The system must remain useful when no candidate is accepted.

## AI legibility

- Free text from archives, repositories, logs and web pages is data, not policy.
- A human decision is converted into a bounded machine record before execution.
- An AI does not infer capital, credential or irreversible authority from general intent.

## Failure rule

If the human view and machine view disagree, execution stops and the discrepancy becomes an incident.

## Native integrity failure classes

- `DUAL_NATIVE_MISMATCH`
- `CORRECTION_NOT_REGRESSION`
- `HUMAN_AGENCY_BYPASS`
- `PREMATURE_STACK_SELECTION`
- `P0_PRECEDENCE_BREACH`

These are control failures, not style preferences. Each produces a candidate delta and remains non-authoritative until Robert decides.
