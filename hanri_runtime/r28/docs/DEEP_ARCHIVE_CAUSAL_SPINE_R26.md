# Deep Archive Causal Spine R26

## What changed in this pass

R25 compared origin and current state. R26 inserts the missing middle: the material correction that changed the path. Six cross-source causal spines were built and source-bound.

## Spine 1 — archive method

```text
Origin: unpack, manifest, deduplicate, raw-first
Pivot: exhaustive meta-audit distinguishes coverage, probes and root causes
Current: scope-bound coverage certificates and causal frontier scanner
```

The durable rule is not “read everything.” It is “define the scope, preserve raw bytes, issue reopenable receipts, and stop when no decision changes.”

## Spine 2 — unified core

The original Archive/Trading/Memory three-contour vision is coherent as product intent. The July meta-audit shows the first implementation accumulated parallel authority and fallback paths. MAIN-033 then proved that the current canonical filesystem root still lacks one verifiable root Git baseline.

Decision: preserve the shared substrate goal, but implement only a minimal evidence/control kernel in a new repository after equal experiments.

## Spine 3 — recursive self-improvement

Historical “self-improvement” often meant repeated prompts, heartbeat prose, Canvas claims and claimed internal activation. Robert's corrections converted that into the proof-first system. HANRI R26 implements only an external bounded loop:

```text
event → deterministic defect → minimal candidate → falsification → Robert decision
```

No model-weight update, no self-application and no hidden background model process.

## Spine 4 — completeness

`99/99` is meaningful only for the exact recovery payload. It does not close Source-001 chronology, missing attachments, legacy exports, current returns or session-loss mechanisms. R26 makes completeness a typed scope rather than an adjective.

## Spine 5 — security

ContinuityOS confirms a general anti-pattern: adding new guards without deleting weaker paths produces fail-open recovery. MAWorld demonstrates a stronger design direction but explicitly remains LIVE OFF and lacks several real-environment acceptances.

Decision: promote fail-closed invariants and tests, not the stack or production status.

## Spine 6 — products

The archive's common-core product strategy survives, but labels must split by authority. NFT analytics, OKX execution, Aigochi, Amora and other shells cannot share one status or permission.

## Net improvement

The system now preserves not only where an idea began and where it stands, but which correction made the present state legitimate.
