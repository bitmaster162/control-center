# HANRI-R64 — bounded self-improvement governor

Implement proposal/test/learning functions above Control Center and ContinuityOS.

- observe registered systems;
- detect drift and recurring failures;
- generate improvement candidates with evidence and action class;
- test in disposable copies;
- estimate benefit/risk without invented probabilities;
- request approval according to effect class;
- learn from accepted/rejected decisions;
- never self-apply production changes.

The first regression target is the decision-intake loop. The second is pointer/role-view consistency. The third is return-delivery completeness.
